# Vocabulary Quest
Upload all files and folders to a GitHub repository. In Settings > Pages, publish from the main branch and root folder.

Progress saves automatically in browser localStorage. Save JSON creates a portable backup. Restore JSON imports it. Clearing browser data removes local progress unless a backup exists.

Lists and certificates can be printed or saved as PDF. Lists can also be saved as CSV.

The attached workbook informed only broad IELTS topics and individual vocabulary items. No exercises, sentences, page designs, answer key, or images were reproduced. All learning text and code are newly created.

## Smart Review V2
Each word now has its own learning record: attempts, correct answers, incorrect answers, lapses, current interval, mastery stage, and next review date. The Due Review queue shows scheduled words. Weak Words includes words missed at least twice, words below 60% accuracy after two attempts, or mastered words that were forgotten. Ratings change the next interval: Again returns today, Hard returns tomorrow, Good uses an adaptive interval, and Easy creates a longer gap. A word becomes Mastered after at least four successful recalls and an interval of 21 days or more. All records are included in the JSON backup.
